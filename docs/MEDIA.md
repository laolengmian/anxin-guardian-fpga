# TF媒体契约

本仓库不分发主题图片、旁白录音或实物照片。请准备你有权使用的媒体，放在FAT32根目录，使用8.3文件名：

| 主题 | 图片 | 语音 |
| --- | --- | --- |
| 健康饮食 | PIC1.BMP | PIC1.WAV |
| 安心休养 | PIC2.BMP | PIC2.WAV |
| 个人卫生 | PIC3.BMP | PIC3.WAV |
| 安全用药 | PIC4.BMP | PIC4.WAV |

图片限24位、BI_RGB非压缩、正高度bottom-up BMP：640×480与800×600缩放到960×720居中，两侧各留160像素；1024×576缩到1280×720；1280×720原尺寸。并非任意图片或视频解码器。

语音为48 kHz、16位小端、单声道PCM WAV，format=1，byte rate=96000，block align=2。每页三段、总计12段字幕在RTL/ROM中配置，以实际消费的PCM样本计数推进；文件读完不表示旁白播放完。替换语音时须同步核对字幕及阈值。

中文/字形来自仓库ROM，不是从TF动态加载。Audio Monitor取最终PCM幅度，不是生理波形。健康内容应经适当专业审核，固定主题不能作为个体化护理处方。
