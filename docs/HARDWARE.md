# 硬件与接线

## 平台与输出

- 开发板：HX4S20C，器件Anlogic EG4S20BG256，基准50 MHz。
- 封装内SDRAM：2M×32 bit / 8 MiB；四幅RGB565画布共7,372,800字节。
- 显示：HDMI_B，1280×720有效区；75 MHz像素、375 MHz串化配置，总时序1650×750。
- TF卡：只读SPI，FAT32根目录，8.3文件名。
- 生命体征采样：主要目标为MAX30102。MAX30105存在部分寄存器兼容点，不因此等同于MAX30102的人体测量用途或性能。

## MAX30102接线

《HX4S20开发板手册-HDL版2410》第7页图2-4和J2扩展口表确认：

| 模块端 | 开发板接点 | FPGA球号 / 约束端口 |
| --- | --- | --- |
| SCL | **J2第31脚，GPIOB_26** | **J12 / `vital_i2c_scl`** |
| SDA | **J2第32脚，GPIOB_27** | **K11 / `vital_i2c_sda`** |
| GND | J2第30脚或第12脚 | GND |
| 电源参考 | J2第29脚，3.3 V | 模块VCC按实际转接板规格核对 |

手册第6页明确扩展IO为3.3 V。SCL/SDA采用 `LVCMOS33`、开漏0/Z驱动，FPGA内部弱上拉关闭。需要共地以及合适的外部上拉；核对模块是否带稳压、电平转换和上拉，不能把裸芯片与转接板供电混为一谈。**J2第11脚是5 V，不能将5 V直接接入FPGA信号或I²C上拉。** 传感器线路不接HDMI DDC的P2/R2。

J12/K11是FPGA封装球号，不是排针第12/11孔。以实物1脚标记与缺口定位，再按手册核对31、32脚；不要直接把电路图上下方向套到实物照片。手册板卡图中，HDMI/USB在上方、网口/TF在下方时，J2/JP2位于左侧、J1/JP1位于右侧。

管脚默认值见 [SENSOR_PIN_CONFIG.json](SENSOR_PIN_CONFIG.json)，手册页码、文件SHA256和映射见 [PIN_ASSIGNMENT_REFERENCE.json](PIN_ASSIGNMENT_REFERENCE.json)。手册PDF本身不随仓库再分发。不同板卡版本仍需按对应原理图复核。

## 六键与提示输入

| 输入 | FPGA球号 | 功能 |
| --- | --- | --- |
| KEY1 / KEY2 | M5 / M3，低有效 | 亮度增 / 减 |
| KEY3 / KEY4 | M4 / L3，低有效 | 音量增 / 减 |
| KEY5 / KEY6 | J3 / J4，低有效 | 自动轮播开关 / 下一主题 |
| Warning / Emergency | C8 / C7，高有效 | 两级业务提示，Emergency优先 |

依据同一J2表，六键M5/M3/M4/L3/J3/J4对应J2第4/5/6/7/8/9脚；体征I²C使用第31/32脚，约束检查拒绝复用已占用球号。实体六键模块按3.3 V、独立低有效输出及其实际上拉配置连接。

Warning/Emergency由外部开关触发，不是算法自动判断病情。体征采集与显示上板功能实测通过，见 [实板记录](validation/BOARD_TEST_RECORD.json)；精度、运动抗扰与具体光学系数标定是独立测量项目，不由一次功能测试推导。

## 移动工程与改线

工程复制到本地英文路径后运行 [工程准备](BUILD.md)。默认使用J12/K11；本地改线保存在忽略的 `build/td/SENSOR_PIN_CONFIG.json`，重新准备不会清掉已保存的本地配置。用 `--unbound` 明确取消绑定。

工程准备记录中的 `recorded_board_test_status` 表示这组接线对应的归档状态，不表示脚本刚刚执行了硬件测试。换成其他管脚时不继承J12/K11的实测结论。
