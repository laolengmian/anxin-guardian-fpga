# 硬件与接口

- 主控：HX4S20C，Anlogic EG4S20BG256，基准50 MHz。
- 封装内 SDRAM：2M×32 bit / 8 MiB；四幅 RGB565 画布共7,372,800字节。
- 视频：HDMI_B，1280×720有效区；75 MHz像素时钟，375 MHz串化配置。
- 媒体：TF卡，SPI只读，FAT32根目录。
- 生命体征采样：MAX30102为主要目标。MAX30105与其存在寄存器兼容点，但并不因此具有相同的人体测量用途或性能保证。

| 输入 | 约束位置 | 功能 |
| --- | --- | --- |
| KEY1 / KEY2 | M5 / M3，低有效 | 亮度增/减 |
| KEY3 / KEY4 | M4 / L3，低有效 | 音量增/减 |
| KEY5 / KEY6 | J3 / J4，低有效 | 自动轮播开关 / 下一主题 |
| Warning / Emergency | C8 / C7，高有效 | 外部业务提示，Emergency优先 |
| vital_i2c_scl / vital_i2c_sda | **未绑定** | MAX30102开漏I²C |

I²C需要共地与适当上拉。先检查实际模块是否含稳压、电平转换以及接口额定电压，不能把裸芯片和转接板供电混为一谈。传感器线路不能直接并到HDMI DDC。不要凭本文或照片猜接未确认管脚。

Warning/Emergency来自外部开关，不是PPG算法自动触发。MAX30102结果是研究/展示用估计；光学结构、运动干扰与标定会影响测量，当前HDL验证不能替代实际标定和医学验证。
