# 算法与采集模块

体征子系统由生产顶层的 `u_vital_processing` 接入，与TF媒体、六键和提示链路并行运行；数据来自I²C读取的Red/IR样本，不来自测试平台的结果端口。

## 文件职责

| 文件（`rtl/`） | 职责 |
| --- | --- |
| `m9_i2c_register_master.v` | 开漏主机、重复START、连续读、末字节NACK、clock stretching与超时 |
| `m9_max3010x_acquisition.v` | 软复位、ID检查、寄存器配置、FIFO指针/溢出检查、六字节样本解码与故障重试 |
| `m9_ppg_rate_estimator.v` | 自适应包络阈值、迟滞越阈、周期合法性、一致性检查与四周期估计 |
| `m9_ppg_vitals.v` | 两波长滤波、AC/DC窗口统计、血氧比值与IR低频呼吸调制提取 |
| `m9_integer_sqrt.v` | 迭代整数平方根 |
| `m9_unsigned_divider.v` | 无符号串行除法，包含除零处理 |

## 采样与握手

地址0x57，Red/IR各18位，100 Hz。数据流通过 `sample_valid` / `sample_ready` 背压，间断使用 `sample_gap` 清除不连续状态；FIFO溢出和器件失联进入相应恢复过程。

## 心率

Q8滤波状态配合两级1/16基线抑制、1/4低通和1/64包络。先越负阈值使能，再越正阈值确认脉搏；合法周期对应35–220次/min。四个完整周期累计后计算：

```text
HR = floor(60 × Fs × 4 / (P1 + P2 + P3 + P4))
```

周期明显突变会重建当前周期组，避免将不相容的旧新间隔直接混合。

## 血氧估计

1024点非重叠窗口，在100 Hz下为10.24秒。两路交流平方和与原始直流均值形成AC RMS/DC，再计算：

```text
R = (ACred × DCir) / (ACir × DCred)
SpO₂ = A − B × R
```

平方根和除法使用串行整数运算。默认A=110、B=25，以Q8参数配置；这是算法换算配置，不是对任意模块和光学条件都有效的已标定测量精度。

## PPG推导呼吸率

IR慢分量1/64、长期基线1/1024，差值经过两级1/128低通，再执行迟滞检测和四周期估计。合法范围6–40次/min。它依赖PPG低频调制，无独立呼吸传感器；呼吸调制不足可以仅使RR无效。

## 原子显示与无效化

三项8位数值、3×12位BCD、三有效位与两来源位共65位，在100 MHz系统域与75 MHz显示域之间握手，帧边界提交。无接触、断流、饱和、周期不足或分母异常撤销对应有效位，显示横线。

100 Hz只定义原始采样间隔；心率/呼吸率需要完整周期，血氧需要完整统计窗口，不按每10 ms输出三项新估计来解释。

## 验证

`sim/`的原始波形和I²C模型是离线测试环境，不参与终端运行。已归档HDL、上板功能和手册核对记录分别见 [validation](validation/README.md)。
