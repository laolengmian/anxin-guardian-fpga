# 发布前验证记录

此目录归档公开源码副本在 Windows / Icarus Verilog 中执行的本地验证结果。
它不是传感器实采、TD物理实现或GitHub Actions结果；Linux干净环境尚未在本轮执行。

- [TEST_REPORT.json](TEST_REPORT.json)：七组套件状态、测试源码SHA256、执行范围。
- [algorithm_results.json](algorithm_results.json)：13组原始PPG输入的末段有效比例和输出中位数。
- [top_elaboration_status.json](top_elaboration_status.json)：可见顶层展开范围与未随仓库分发的厂商模块。

日志、CSV和局部VCD在复跑时写入仓库根目录的 `results/`；确定性输入由脚本生成到 `sim/vectors/`。归档报告中的日志文件名指这些复跑输出，而不是此目录内的额外附件。仓库不包含编译的vvp程序或厂商加密体。

## 七组测试

1. 整数除法、整数平方根和中途复位。
2. I²C初始化、FIFO顺序/回绕、背压、NACK、溢出、clock stretching和超时。
3. 异步时钟原子快照、突发合并与源/目的分别复位。
4. 13组确定性原始Red/IR波形，每组9000样本/90秒等效采样。
5. 修改血氧系数后的独立配置测试。
6. 4500组原始样本经I²C/FIFO→算法→CDC→显示的链路及断开后有效位撤销。
7. 采集/算法子系统的Verilog-2005编译。

## 原始波形结果

| 工况 | 目标HR / SpO₂ / RR | 输出中位数或有效状态 |
| --- | --- | --- |
| 正常 | 72 / 98 / 12 | 72 / 98 / 12 |
| 较慢心率 | 48 / 96 / 8 | 48 / 96 / 8 |
| 较快心率 | 144 / 95 / 24 | 143 / 94 / 24 |
| 较低血氧 | 90 / 90 / 18 | 90 / 90 / 18 |
| 加噪 | 108 / 97 / 15 | 108 / 97 / 15 |
| 平直、低幅无接触、饱和、微弱脉动 | 应无效 | 三项无效 |
| 无呼吸调制 | 72 / 98 / RR无效 | 72 / 98 / RR无效 |
| 频率阶跃稳态 | 120 / 90 / 20 | 120 / 90 / 19 |
| 接触丢失、脉搏丢失 | 丢失后应无效 | 三项无效 |

HR/RR单位为次/min，SpO₂为%。这些误差只描述特定激励下的整数输出，不是人体测量准确度指标。默认光学系数仍需实测标定；完整音视频、外部IP、物理时序和板上稳定性不在上述七套件覆盖范围内。
